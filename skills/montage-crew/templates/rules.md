# My editing rules — the skill's memory for THIS user
Every lesson from every video lives here as one rule. The skill writes this file for you after each delivery (SKILL.md §8); you can also edit it by hand.
It wins over the skill's built-in defaults (`references/craft/12-field-lessons.md`). Newest rule wins; retire a rule instead of leaving two that contradict.
Agents read the rules whose **owner** is them (+ `all`). QA checks EVERY `active` rule before delivery.

Format: `R<nn> · owner · rule` — then `why:` (your words / what went wrong), `seen:` (video names + dates; each repeat adds one), `check:` (how QA verifies), `status:` active | retired (reason, date).
Owners: cutter · scout · picture · captions · motion · audio · cover · writer · qa · leader · all.
Example (format only):
`- **R01 · captions · <the rule in one line>.** why: <…>. seen: <video> <date>. check: <…>. status: active`
