# Style library — index

Two places, ONE card format (`<slug>/style.md`, template in `references/learn.md` › Style card):
- **Built-in** (ships with the skill, read-only): `{{SKILL_DIR}}/styles/<slug>/style.md` — the 12 below.
- **Learned** (the user taught them): `{{DATA_DIR}}/styles/<slug>/style.md`, listed in `{{DATA_DIR}}/styles/INDEX.md` (same columns). A learned slug never reuses a built-in slug.
New built-in cards can ship in later versions (style packs) — they appear here with no other change.

`kind`: **look** = palette + type + signature pieces · **grammar** = how the whole edit is structured (craft/09 §7). A video uses one grammar and at most one look (or the brand).

| slug | kind | one-line look | best for |
|---|---|---|---|
| `premium-soft` | grammar (DEFAULT) | soft karaoke words, huge hero phrase half behind the head, light-led motion | personal brand, authority, any talking head |
| `explainer-board` | grammar | flat board inserts, UI mockups pop on the spoken noun | education, tool explainers, idea-only |
| `editorial-collage` | grammar | grayscale cut-outs, paper, one colour disc, phrase every 1–2 s | hooks, intros, manifesto, idea-only |
| `chapter-looks` | grammar | one look per sentence, loud transitions between | short cinematic 20–40 s |
| `espresso-glow` | look | chocolate, ivory bloom titles, copper, 3D UI cards | warm premium, lifestyle, food |
| `navy-kashida` | look | navy, cream kashida titles, glass arch, liquid tag | calm authority, finance, education |
| `neon-blue` | look | night navy, neon caption pairs, blur-cuts, orbit icons | tech, AI, apps, gaming |
| `gold-neon` | look | near-black, yellow neon kashida, 3D edge cards, stack lists | marketing, results, Q&A |
| `pink-palace` | look | deep rose, flat white type, giant numerals behind the speaker | listicles, beauty, sections |
| `teal-eco` | look | teal room, counter hero, dark name pill, neon trail | startups, health, product |
| `outline-doc` | look | natural footage, colour-coded outline bars, chapter HUD | lists, tutorials, screen recordings |
| `before-after-board` | look | small Before + big After, tilted timeline + playhead | portfolio / result showcase |
