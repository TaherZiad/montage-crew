# GitHub agent skills for video editing: what we take

Scope: Claude Code / agent skills and repos for talking-head editing, captions, motion graphics, short-form pipelines, Resolve/AE/Premiere control, explainers, plus Arabic tooling. Found with `gh search repos` (about 40 queries, English, Chinese, Vietnamese, Indonesian and Arabic keywords), the awesome-claude-skills lists (ComposioHQ, travisvn, BehiSecc) and wilwaldon/Claude-Code-Video-Toolkit. Top repos were shallow-cloned and their SKILL.md, references and core scripts were read.
Copied text lives in `references/external/<repo>/` (MIT/Apache only, each folder has its LICENSE; file names flatten the source path with `__`). These files are **external reading, not house rules**: where they conflict with SKILL.md or craft/09 (soft text, no boxes, Arabic never split per letter, RTL), our rules win.

## Arabic finding
**No Arabic reel-editing skill or Arabic caption pipeline of any quality exists on GitHub.** The Arabic searches (arabic captions/subtitles/video editing, «مونتاج», «تفريغ صوتي», «ترجمة فيديو») return only image-captioning projects, transcription bots and Aegisub helpers (Bilal2453/Arabic-Ruler, MIT, cleans Arabic subtitle files). The only RTL-aware video pipeline is erfsalehi/Tovo-Content-Localization: it shapes captions with Pillow + arabic_reshaper + python-bidi and draws them as "pill" overlays, which is the opposite of our soft-text rule. Our Arabic layer (kashida, RTL reveals, dialect checks, Quran rule) stays ahead of everything published. Every method below is ported from Latin, Chinese or Vietnamese work and adapted.

## Methods to adopt (actionable rules for OUR pipeline)

### A. Cutting (mc-cutter, `jumpcut.py`, `story.py`)
1. **Transcript-guarded silence cuts** (AIEV). `silencedetect` hits inside words: unvoiced finals and syllable breaks (in Arabic: ت/ك/ق/ط stops, ه/ح breath) read as "silence". Rule: subtract an audio silence only where it does not overlap a word's core `[start+0.04, end−0.04]`, or where it lies inside a Whisper-stretched word tail longer than 0.25 s. Log every rejected silence.
2. **Per-file silence threshold** (AIEV, auto-editor). Our fixed `--silence -38` is a guess. Measure the noise floor first (10th-percentile RMS of the non-word gaps), set the threshold about 6–8 dB above it, and print the chosen value with the reason. Sanity check: the total cut silence should be about the sum of the inter-word gaps (±20 %).
3. **30 ms fades at every exposed edge** (video-use rule 3, AIEV measured). Mid-speech joins without a fade clicked in 3 of 4 cases. Ours fades 10–12 ms. Raise it to 30 ms, clamp the fade to ≤ D/2, and put `afade` after `asetpts`. Use the same rule for any clip extract.
4. **Cut padding window 30–200 ms** (video-use): 50 ms before the first kept word and 80 ms after the last is a good talking-head default. Prefer silences ≥ 400 ms as cut points. Gaps of 150–400 ms are allowed after a visual check. **Never cut a gap under 150 ms** (mid-phrase).
5. **Repeated-POINTS pass, not only retakes** (AIEV step 3, koubo). `story.py` finds similar sentences within the next 2. The cutter must also read the whole transcript for the **same point restated non-adjacently** (short and stumbling first, fuller later). Keep the most complete version. A later short echo («مثل ما قلت») is cut. Re-read the kept text for broken back-references. Output a table: `time | cut | reason | kept`.
6. **Take-selection order** (koubo): eliminate in tiers, and use the next tier only to break a tie: ① incomplete or contradictory information → ② slips, restarts, unwanted repetition → ③ unclear audio (noise, plosive, breath) → ④ visual (shake, focus, eye-line). Look at video only for the finalists of tier ③.
7. **A long pause is a candidate boundary, not a split** (koubo). Split there only if both sides are valid and independently meaningful. A false start next to its correction keeps only the correction. Prefer the later complete correction, but keep genuinely additive follow-ups.
8. **False-positive list for the mistake detector** (student-kit): emphatic repetition («أبد، أبد»), rhetorical doubling, lists, and copula-then-question are not stutters. Read every candidate in context. A clean take with zero cuts is a valid result.
9. **Timing-truth check after the cut** (natyang, student-kit). Re-run `transcribe.py` on `cut.mp4` (small model is enough) and compare it word-by-word with `words_cut.json`. Any word missing or shifted > 0.1 s means the cut swallowed a consonant. This extends `story.py sync`.

### B. Captions (mc-captions)
10. **Dynamic-programming phrase segmentation** (koubo `adaptive_subtitles.py`, copied). Port it to Arabic instead of greedy chunking. Cost terms: length target 10–20 letters (soft 20, hard 24, matching craft/09's ≤ 20), duration ≤ 3.2 s, avoid fragments < 4 letters or < 0.55 s, strong boundary at word gap ≥ 280 ms and soft at 160–280 ms. **Break before connectors** (MSA/common: لكن، لأن، يعني، فـ، حتى، إذا، لو، مثلاً، أي; dialect variants such as بس، وهسّه / ودلوقتي، يعني شنو / يعني إيه — adapt to the profile's dialect). Never end a line on a preposition or a dangling «و/ب/ل/من/على/عن/في». Protect named phrases (Claude Code، ذكاء اصطناعي) from splitting. Choose the globally best sequence. After segmentation, report how many lines exceed the soft and hard limits.
11. **Captions are timed from the first and last word of each line on the output timeline**, never spread proportionally (koubo, video-use rule 5). Grow a cue to 3 words rather than flash one < 0.35 s (video-use).
12. **Emphasis budget** (natyang): ≤ 1 emphasised phrase per caption line (2 only when both are essential). Emphasise nouns, numbers, contrasts and promises, never filler. This matches our ≤ 1 in 6.
13. **Captions are applied last** in any ffmpeg composite (video-use rule 1). In Resolve the caption track is the top video track.

### C. Story, hook, retention (leader brief + `story.py`)
14. **The first-3-seconds gate is a separate edit** (student-kit). Write the *benefit*, the *unresolved question*, the *visible evidence by 3.0 s* and the *payoff timestamp*. Build **3 materially different openings** (problem-first / result-glimpse / recognition-first) from the same true speech and compare their first 3 s on cheap renders. Record why the winner won. The opening must also work muted.
15. **OPEN-LOOPS ledger** (student-kit, `curiosity-and-entertainment.md`). Keep one main loop and ≤ 1 secondary loop open. Each loop has a planted object, a setup time, reminders or partial answers and a closure, and the closure lands before the CTA. A recurring object without a state change is a callback, not a loop. This goes in the brief (no file in the delivery folder; delivery mode).
16. **Anti-duplication audit** (student-kit). Narration plus captions already carry the words, so a graphic must show the example, relation, evidence or consequence. Remove a third restatement of the same sentence. This sharpens our "show, don't tell".
17. **Payoff-word sync** (video-use). Start an explanatory MG `reveal_duration` before the payoff word so its *landing* frame hits that word, not its start. Bind sub-element reveals to their own spoken nouns, never `index*0.4` staggers (student-kit). Target ±2 f, with ≤ 0.15 s deliberate anticipation.
18. **Reading time floor** (video-use, hculap): an explanatory card needs ≥ 3 s (5–7 s typical, 8–14 s for a diagram). Key text needs ~0.3 s per word on screen. Never reveal two independent elements at once: one thing, a pause, then the next.
19. **Gap watchdog** (student-kit quality gates): no stretch > 2.2 s without a visual event unless it is a deliberate conviction hold (record why). This complements "visual change every 2–4 s".
20. **Hook patterns + retention-curve debugging** (iart `retention-pacing.md`). Early drop = hook. Flat-then-drop mid-video = body too sparse: add interrupts and tighten to 2–4 s. Iterate the hook first.

### D. Motion graphics (mc-motion)
21. **Mechanical anti-slideshow test before showing anything** (bang-motion `anti-ppt.md`). Fail if any 2 are true: ≥ 3 scenes are separate sections faded in and out; > 2 text tiers in one scene (kicker + title + body); Ken Burns is the only motion; every transition is fade/scale-bump/leak; three parallel feature tiles; the structure is hook → feature → feature → promise → logo → CTA; a "miniature" (camera zoom < 1.08, subject thumb-sized). Run it on our HyperFrames HTML.
22. **Every MG beat is an action with an outcome** (student-kit, opus kinetic-reel): a card swivels and its criteria tick, a key seats and the project starts, a stack assembles. No settle-and-freeze cards and no identical idle bob on every object. Compare adjacent beats as silhouettes with the text hidden: if two read as the same reveal, redesign the weaker one. This extends the metaphor-per-sentence rule in `mg-recipes.md`.
23. **Shape-continuity transitions inside a chapter** (opus kinetic-reel): zoom through the element the eye is on, or iris out of the thing that just lit up. Use hard cuts plus an impact only for chapter slams. Transitions are 0.45–0.6 s, never 3 of one kind in a row. About half the cuts carry **no** SFX.
24. **Persistent world + spotlight for list/explainer reels** (student-kit `video-storytelling`). In a multi-point reel, keep earlier items on screen dimmed instead of replacing them: active element luma 200–235 (opacity 1.0), context 120–150 (0.56), spent 85–105 (0.33), no label below 90. Exactly one element is at full brightness. Camera moves (world / region / detail) do the work of cuts. **Merge a reframe and a wipe on the same subject into one gesture** (shared power2.inOut, same landing frame), because two sequential moves read as a glitch. No label within 60 px of a frame edge during camera moves.
25. **Key layout for explainer/news reels** (AIEV `key-layout`): one main key (2–6 words) in the top band for the whole reel, hidden while a hero title is on; related keys (1–4 words) timed to the spoken point, held 2.5–4 s, ≥ 1 s apart, ≥ 4 s per key. **Adaptation:** soft text only (no pill or chip, per the default soft-text rule), and the bands sit outside the zoom wrapper so they don't scale on punch-ins.
26. **Fonts fail silently** (video-use): in every HyperFrames composition, `await document.fonts.ready` and then `if(!document.fonts.check('800 80px "Alexandria"')) throw`. A fallback face ships with no error, and for Arabic that also breaks kashida metrics.
27. **Logo fidelity** (student-kit): official or supplied asset only, with source URL and checksum saved in `assets/manifest.json`. Check every encoded occurrence against it. If no verified asset exists, use the brand name as plain text. Never draw an approximate mark.
28. **Honest data label** (opus kinetic-reel): anything illustrative (example UI, schematic numbers) carries a small «توضيحي» tag. This extends our "every number is one the speaker said".

### E. Sound (mc-audio)
29. **Measure each SFX attack**: start the file `attack` seconds before the contact frame, where attack = first sample above −30 dBFS relative to its peak. Our `manifest.json peak_time_s` already covers this; check new SFX the same way.
30. **Density**: ~8 tied SFX in 18 s reads as designed, ~20 reads as generic (video-use). Score anticipation, contact and release separately, and let some cuts pass silently (student-kit, opus). A request for "more SFX" means a richer event score, not louder music.
31. **"Music too loud" fix must be relative**: lower the bed relative to the reviewed version and verify the bed-to-voice ratio after normalisation. A quieter master is not the fix (student-kit). Measure loudness per section (dialogue / music-only / end card). An end card 15 dB under the dialogue is a bug (video-use).

### F. QA (mc-qa)
32. **Critique loop with scores** (hculap, methods only). Render one still per beat → one labelled contact sheet → score 1–10 on hook (first 2 s), phone readability (360 px wide), motion, variety, composition, brand/asset accuracy and sound sync → fix the worst 3 → re-render only those moments. Stop when all scores are ≥ 8. Report and stop after 2 rounds that don't raise the lowest score, or after about 8 rounds. Cheap stills first, a draft video for motion, the full render last.
33. **Hunt list** for every QA pass: text overlapping during swaps, linear slides, dead beats, the same composition twice in a row, type touching frame edges, low contrast, a black/flash frame or one-frame pop at cuts (check contiguous frame strips across each cut, video-use self-eval), waveform spikes at joins, and captions hidden behind overlays.
34. **Phone-scale check**: also downscale the QA sheet to 360 px width and confirm every word is still readable (hculap `inspect.sh phone`).
35. **Critic sub-agent for anything published** (video-use): a fresh agent gets the render + brief and is told to *roast, not praise*. It returns a verdict, ranked problems with timecodes and evidence, and the top 5 fixes. `mc-qa` already exists; give it this exact brief. **Cap self-eval at 3 passes**, then report the remaining issues instead of looping.
36. **State review modality honestly**: we cannot listen. Say "measured" (LUFS, RMS, onset times), never "sounds good" (video-use, student-kit, opus).
37. **Validator negative controls** (student-kit): when adding a QA script, prove it fails on a caption shifted 0.3 s, a 1-frame gap and a missing word before trusting a green result.
38. **Reference-reel analysis by change-based keyframes** (claude-real-video): pick frames on scene change plus dedup, plus forced frames at caption cues, instead of fixed 1 fps. Fewer images, nothing missed. Candidate upgrade for `sheet.py` reference-reel measurements.

### G. Team / workflow
39. **Animation sub-agent brief template** (video-use): one goal ("Build ONE overlay: … nothing else"), absolute output path, exact tech spec, palette hex, font path, a frame-by-frame timeline with easing, an anti-list, a deliverable checklist, and "do not ask questions; pick the obvious interpretation". One agent = one file. Use it for `mc-motion` when it fans out per beat.
40. **Resolve-native jump cuts (optional)**: `auto-editor cut.mp4 --export resolve` gives the user an editable Resolve timeline of the silence cut to open and nudge. Consider it when the user wants to touch the cut themselves.

## Do not adopt (and why)
- **"Ask → confirm strategy before any cut"** (video-use rule 11, koubo, natyang gates, student-kit review gate). It conflicts with the skill's default *autonomous, final-video-only* mode (unless the user's `rules.md` asks for checkpoints). We keep their checks but run them internally.
- **Hosted ASR (ElevenLabs Scribe / Volcengine) and "never run Whisper locally"** (video-use). We run faster-whisper large-v3 locally (an NVIDIA GPU if present (CUDA), otherwise CPU), and the dialect is proof-read anyway. Their only real point (keep fillers verbatim and word-level) we already follow.
- **Pill/chip related keys, glass caption backgrounds, outline-box captions** (AIEV key-layout, video-use `bold-overlay` force_style, Tovo pill captions). These violate the default soft-text law. Only the timing and band logic is taken.
- **Per-letter / split-text kinetic type, UPPERCASE chunking, letter-spacing animation** (bang-motion techniques, opus kinetic-reel, iart kinetic-typography). They break Arabic joining (craft/10). Use word, line or clip-mask reveals with kashida instead.
- **Code-drawn canvas engines + synthesised scores as the main engine** (hculap, opus kinetic-reel, bang-motion). We stay on HyperFrames → ProRes alpha → `scripts/compose.py`. Synth music is fine only as an option, never instead of the SFX library.
- **Remotion / CapCut JSON / JianYing / Premiere / After Effects pipelines** (remotion skills, video-autopilot-kit, koubo JianYing adapter, AE/PR MCPs). Not our engine: we assemble with `scripts/compose.py` (final MP4) plus the FCP7 XML for Resolve/Premiere.
- **AI video-model restyling of the speaker** (A-roll restyling via Gemini Omni/Seedance) and generated B-roll as evidence (student-kit Kie.ai). It is paid, it risks the speaker's likeness, and it breaks the "no fake proof" rule. We use real assets.
- **Re-transcribing the cut as the ONLY timing source** (natyang). Remapping words through the EDL (`jumpcut.py`) is exact. Use the re-transcription as a *check* (method 9), not a replacement.
- **Playback speed-up as a default**. Koubo also says it must be approved per project. Default: original voice, no stretch.
- **Copying hculap or jincheng text**: no licence and non-commercial respectively. Methods are summarised above in our own words only.
- **pireel** (AGPL-3.0): licence would infect anything we ship. Skip.
