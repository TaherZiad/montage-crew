> For users whose profile editor is DaVinci Resolve (free or Studio). ## Built-in transitions (Edit → Effects → Toolbox → Video Transitions)
- Cross Dissolve (Ctrl+T; 6–10 f for reels) · Additive Dissolve (2–4 f under glitch/flash) · Dip to Color (white 4–6 f = flash cut) · Blur Dissolve · **Smooth Cut** (Studio only: Better + Speed Warp, 2–6 f, hides jump cuts; punch in slightly for edge artefacts) · Push/Slide (border, feather, motion blur; 12 f ease in/out; save via Create Transition Preset) · Fusion transitions (Brightness Flash, Foreground Wipe, zoom/shake/warp) · **21 free**: Mosaic Center/Dissolve/Edge Wipe, Perspective, Posterize, Ripple Warp, Shape, Shatter, Three Color Flash.
- **Handles rule**: transitions eat frames both sides → "Insufficient handles" → trim first. Alignment Center/Start/End. Copy/paste transitions with Ctrl+C/V on edit points. (API 21.1: `AddTransition` also needs handles.)

## Recipes (30 fps; base = Adjustment Clip over the cut → Open in Fusion; ease with S/F/Out Cubic; save to Power Bin / Edit Template)
- **R1 Smooth zoom-blur**: adjustment clip ±15 f; Transform Size 1.0 → **2.5** (last frame A) → **0.25** (first frame B) → 1.0; Edges Mirror; motion blur max; spline peak at the cut. Pro: Directional Blur type Zoom **before** the Transform; blur centre linked to Transform pivot; Transform (not XF) for PNG edges.
- **R2 Punch-in**: Zoom 1.0 → 1.3 over 10 f, aim with **Anchor Point** (not Position), Ease Out / Ease In; chained moves 2→2.5→1.7→1 each 10 f.
- **R3 Whip**: ±15 f; Transform Center X 0.5 (−8 f) → 0 (last A) → 1 (first B) → 0.5 (+8 f); Mirror/Wrap; motion blur 8, shutter 180–270; S-curve. Short: −1 / 0.5 on cut / 0 over ±4 f. Vertical: animate Y, blur angle 90.
- **R4 Clean shakes (16 f, cut at f7)**: A vertical — Camera Shake X .1 Y .9 Rot .5, strength/speed 0→.74 (f7–8)→0 (f15), shutter 180→360→180, Directional Blur 90° 0→.6→0. B flash — shake .7/.7/.7, strength/speed 1→0 over 15 f, Rectified Sine, blur length .1 angle 130 glow .2 → 0, Out Cubic. C horizontal flash — X1 Y.8 R.8, strength .4 speed .75 at f7–8, glow 0 (f5) → .8 (f7) → 0 (f9).
- **R5 Glitch (no Fusion)**: 6–10 f adjustment clip with Flicker Addition + Camera Shake (Motion 2, Speed 2, Square Wave, Reflect) + glitch overlay (Subtract/Color Dodge/Difference/Exclusion) + 2–4 f Additive Dissolve + duplicated last frames of A on Exclusion slightly offset (RGB ghost) + JPEG Damage + glitch SFX. 21: Hologram Glitch / Mosaic Edge Wipe.
- **R6 Light leak / film burn**: overlay above the cut, brightest frame marked and snapped to the edit, Screen (or Add); rotate 90° + zoom for 16:9 overlays; no overlay → Glow gain 0→high→0 over 6 f + warm Dip to White.
- **R7 Blink**: 3 f each side Radial Blur 0→high→0 + inverted soft Ellipse on a solid, level 0→small→0.
- **R8 Blur-in text**: Text+ Y −900 → land over 10–12 f + Directional Blur 90° .86→0 over 12 f, eased; optional shake transition at landing; plain blur-in = Gaussian 1→0 + opacity + zoom 1.1→1 over 6–8 f.
- **R9 Freeze intro** (Magic Mask = **Studio only**): freeze frame 2–3 s, duplicate on V2, mask + "Outer Stroke" template, bottom monochrome (RGB Mixer), ink splash (Darken), title; zoom 1→1.15, title slides, splash scales; 2–3 f Brightness Flash. Free: Fusion Polygon roto + tracking, or our external alpha matte.
- **R10 Text behind subject**: V1 clip, V2 Text+, V3 clip again with alpha from Magic Mask (Color page: node → Add Alpha Output) — **Studio only**; free = external alpha matte on V3.
- **R11 Speed ramp**: retime points, middle 25 % (120 fps source), smooth curve, Optical Flow + Speed Warp (Studio only)/Enhanced Better; adjustment clip with Optical Flow → Vector Motion Blur; disable while editing, render in place; same-direction clips only.
- **R12 Trendy mask effects** (Studio-only mask): build-up (3 masked layers fly in Y −900→0 12 f + blur), knockout (2–3 f photos between subject and bg + grain + glow), mask grid (Mosaic + Bitmap), time freeze (25 % Speed Warp + mask + zoom 1.3 + B-roll behind).
- **R13 Object wipe**: keyed prop crossing (Delta Keyer), clip A Crop Left keyframed to follow the prop.
- **R14 Continuous push**: one adjustment clip across photos, zoom 1.0→1.15.

## Templates & Reactor
Sources: built-in 21 (try first) · MrAlexTech free/pay-what-you-want .drfx (Magic Zoom etc.) · Mixkit free `.comp` transitions (Mixkit License) · Motion Array free, Videokits, DVBlend (check licences) · BMD forum "Master Plugins & Templates List" · creators' overlay packs.
Template folder: Resolve's Fusion `Templates\Edit\{Transitions,Titles,Effects,Generators}` (find it via Effects → Templates → right-click → Show Folder). `.setting` → matching folder + refresh/restart; `.drfx` → drag onto Fusion node area (21.1 Macro editor also loads .drfx); `.comp` → import onto an adjustment clip / Fusion composition.
Reactor: WSL community package manager; installer only from steakunderwater.com thread or gitlab.com/WeSuckLess/Reactor (read it first; runs with user rights); installs a `Reactor` folder + `Reactor.fu` under Resolve's shared Fusion folder; Workspace > Scripts > Reactor — **note: 21.1 free blocks Scripts-menu items, so Reactor's menu may not open on free 21.1**. Krokodove is now built into 21 (no Reactor needed). Don't install templates/scripts from reuploads. Ask the user before installing any template pack.

## Mistakes / QA
No handles · linear keys · aiming zoom with Position (bounce/black bars) · Edges = Black · blur after Transform · XF motion blur halos on PNG · Studio FX on free (watermark) · Magic Mask Faster/one direction · heavy Fusion left enabled while editing · overlays in Normal blend · overlay peak not on the cut · ramping opposite-direction or 25 fps footage to 25 % · too many transitions (hard cuts default, ≤ 1 effect per 3–5 s) · guides left on · unknown template sources.
QA: frame-step ±3 f around every cut (no black edges/wrong-clip flash/mask pop) · on beat, SFX within 1 f · **no Studio watermark** · text in safe area, correct behind/in front on every frame · ramp/smooth-cut artefacts checked · re-enable disabled adjustment clips, guides off · 10 s test render of the heaviest section, then full H.264/H.265 1080×1920 30 fps.
